# knowledgebase/

Source documents go here. Subfolders are kept as metadata, so grouping by
`guidelines/`, `pharmacology/` and so on is worth doing.

Supported: `.pdf`, `.txt`, `.md`

## Filenames matter

Publication year is read from the filename. A 2009 recommendation and a 2024 one
are not interchangeable, and every citation shows the year so the reader can
judge how current it is.

```
guidelines/psoriasis-guideline-2024.pdf
pharmacology/isotretinoin-monograph-2021.pdf
```

is better than `scan1.pdf`.

## After adding or changing files

Open the app, go to **Documents**, and press **Index new documents**.

Only new and changed files are processed, so adding 200 pages costs 200 pages.

## Not tracked

The contents of this folder are excluded from git.
